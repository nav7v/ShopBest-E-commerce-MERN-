# ShopBest E-commerce MERN

ShopBest is a full-stack e-commerce application built with the MERN stack. It includes user authentication, product browsing, cart and checkout flow, order tracking, and an admin dashboard for managing products, users, and orders.

## Tech Stack

- Frontend: React, Redux
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- Email: Nodemailer
- Payment integration: Razorpay

## Features

- User registration and login
- Product catalog and product details
- Shopping cart and checkout
- Order placement and order status updates
- Admin dashboard
- Product management
- User management
- Order management

## Project Structure

- `frontend/` — React app
- `Backend/` — Express API server

## Setup

1. Clone the repository
2. Install frontend dependencies:
   ```bash
   cd frontend
   npm install
   ```
3. Install backend dependencies:
   ```bash
   cd Backend
   npm install
   ```
4. Create a local `.env` file based on `.env.example`
5. Start the backend server
6. Start the frontend app
